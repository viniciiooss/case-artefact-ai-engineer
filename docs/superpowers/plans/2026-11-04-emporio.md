# Empório da Música Implementation Plan

> **For agentic workers:** executar tarefas com testes e revisão por entrega. A skill
> dispatching-parallel-agents permite delegar UI e revisão depois de fixar os contratos.

**Goal:** entregar um agente de atendimento executável e fundamentado nos arquivos do desafio.

**Architecture:** LangGraph com function calling, repositório SQLite e RAG BM25 do PDF.
Persistência de sessões separada; API FastAPI, web estática e CLI Typer compartilham o serviço.

**Tech Stack:** Python 3.11+, uv, LangGraph 1.x, LangChain, Pydantic 2, FastAPI, SQLite,
pypdf, rank-bm25, pytest, Ruff, Docker.

**Spec:** docs/superpowers/specs/2026-11-04-emporio-design.md

## Global Constraints

- Valores monetários em centavos; entradas decimais convertidas com Decimal/HALF_UP.
- Dados originais imutáveis; bancos/cache locais fora do Git.
- demo não é LLM; nenhuma integração remota é silenciosamente simulada.
- Autorização de pedidos no servidor e limitada à sessão/pedido validado.
- Nenhum envio externo, publicação ou alteração operacional.
